# Real-universe catalogues

These files feed the "Real" universe mode (`src/universe/RealUniverse.cpp`, `buildRealUniverse`).
They are generated by `tools/fetch_real_catalogs.py` from public catalogues and committed so the app
works offline (but see the licence note on `galaxies.bin` below before publishing it).

| File | Size | Content |
|---|---|---|
| `stars.bin` | 4.4 MB | 119,613 stars from the HYG Database v4.4, the Sun first; 3,691 names |
| `galaxies.bin` | 2.9 MB | 45,307 galaxies: Local Group (McConnachie 2012), Local Volume (UNGC), 2MASS Redshift Survey; 14,194 names |
| `manifest.json` | 7 KB | input checksums, counts, calibration constants, corrections applied, output checksums |

## Regenerating

```
python3 -I tools/fetch_real_catalogs.py                 # downloads into the cache, then converts
python3 -I tools/fetch_real_catalogs.py --offline       # uses only the cache
python3 -I tools/fetch_real_catalogs.py --cache DIR --out DIR --refresh
```

Only the Python standard library is used. Downloads go to
`/home/chubs/.claude/jobs/449dea01/tmp/real/cache` by default (`--cache` overrides) and are reused.
Every input is verified before use, in the cache and after each download:

* Static archive files (HYG v4.4, the UNGC, McConnachie and 2MRS tables) against pinned SHA-256
  checksums.
* VizieR query results (2MASS XSC, RC3), whose comment lines carry dates, against pinned checksums of
  their header and data rows, plus the expected columns and a minimum row count.
* The HYG v4.1 fallback (not pinned) for the columns the script uses, complete rows and at least
  110,000 of them.
* Each download against its `Content-Length` (Python returns a short body without an error when such
  a connection drops); a chunked reply cut short (`http.client.IncompleteRead`) is caught too. A
  failed download moves on to the next attempt or mirror and never aborts the script.

`--no-verify` accepts input whose pinned checksum no longer matches (a legitimate upstream update;
then copy the new value from `manifest.json` into the script). Each source has a mirror (CDS over plain
HTTP, the CfA VizieR mirror, the GitHub copy of HYG v4.1). Output is deterministic: running the script
twice gives byte-identical files (`manifest.json` lists their checksums), also after a fresh download. A
run takes about 8 s from the cache and 1-7 minutes with downloads (the 2MASS and RC3 VizieR queries are
the slow part).

## Binary format (version 1)

Little-endian. Each file is a 64-byte header, `count` fixed-size records, then a name table:
`nameCount + 1` uint32 offsets into a UTF-8 blob of `nameBytes` bytes (name *i* is
`blob[offsets[i] .. offsets[i+1])`, no terminators). The file size must equal
`64 + count * recordBytes + (nameCount + 1) * 4 + nameBytes`, and `payloadCrc` is the CRC-32 (zlib
polynomial) of everything after the header. The loader rejects files that fail any of these checks,
and skips (and counts) individual records with non-finite or implausible values (for example stars
more than 100 kpc away). Structs are declared in `src/universe/RealUniverse_internal.h`.

### `stars.bin` (magic `BHSSTARS`)

Header: `char magic[8]; uint32 version, headerBytes (64), count, recordBytes (36), nameCount,
nameBytes, payloadCrc, sunIndex; float limitAppMag, radiusPc; uint32 sourceVersion (44 = HYG v4.4),
reserved[3]`.

Record (36 bytes):

| Field | Type | Meaning |
|---|---|---|
| `x, y, z` | float32 | heliocentric ICRS (equatorial J2000) position, parsecs |
| `absMag` | float32 | `V - 5 log10(d / 10 pc)`: the catalogue V moved to 10 pc, so it still contains the real extinction towards the Sun. The loader turns it into an intrinsic absolute magnitude (see "De-reddening" below). |
| `teff` | float32 | effective temperature, K |
| `radiusSolar` | float32 | photosphere radius, R_sun |
| `name` | int32 | index into the name table, -1 if none |
| `hip` | uint32 | Hipparcos number, 0 if none |
| `flags` | uint16 | 1 distance estimated (no usable parallax), 2 Teff from the spectral type (no B-V), 4 hot-star Teff correction, 8 secondary component, 16 literature distance, 32 proper name |
| `reserved` | uint16 | 0 |

### `galaxies.bin` (magic `BHSGALXS`)

Header: `char magic[8]; uint32 version, headerBytes (64), count, recordBytes (60), nameCount,
nameBytes, payloadCrc; float hubbleConstant (70), omegaM (0.3); uint32 reserved[5]`.

Record (60 bytes):

| Field | Type | Meaning |
|---|---|---|
| `x, y, z` | float32 | heliocentric ICRS position, Mpc |
| `diameterKpc` | float32 | optical D25-equivalent major-axis diameter (UNGC sizes corrected for Galactic extinction, see below) |
| `effRadiusKpc` | float32 | measured half-light radius (Local Group dwarfs), else 0 |
| `axisRatio` | float32 | observed b/a |
| `paDeg` | float32 | major-axis position angle, north through east (deterministic random if not measured) |
| `inclinationDeg` | float32 | disk inclination, 0 = face-on |
| `absMagV` | float32 | integrated absolute V magnitude |
| `log10StellarMass` | float32 | log10 of the stellar mass, M_sun |
| `czKms` | float32 | heliocentric velocity (0 if unknown, see flags) |
| `ttype` | float32 | de Vaucouleurs T-type (-6 cE ... 10 Im) |
| `name` | int32 | index into the name table, -1 if none |
| `seed` | uint32 | CRC-32 of the primary identifier (2MASX designation, else UNGC/McConnachie name) |
| `flags` | uint16 | 1 barred, 2 weak bar (SAB), 4 PA measured, 8 has velocity, 16 McConnachie, 32 UNGC, 64 2MRS, 128 RC3 attributes, 256 dwarf spheroidal, 512 morphology guessed, 1024 cluster member |
| `morph` | uint8 | `GalaxyType` (0 spiral, 1 barred spiral, 2 lenticular, 3 elliptical, 4 irregular) |
| `distanceMethod` | uint8 | 0 Hubble flow, 1 redshift-independent (TRGB, Cepheids, ...), 2 cluster member, 3 photometric estimate, 4 literature override |

## How the data were processed

### Stars

* Positions: HYG's equatorial x, y, z (parsecs). The Sun is record 0, named "Sun" (M_V 4.83,
  5772 K, 1 R_sun). The quasar 3C 273, which HYG lists with a proper name, is dropped.
* Effective temperature: Ballesteros (2012, EPL 97, 34008) blackbody formula from B-V (clamped to
  -0.40 ... 2.60). B-V saturates (and is reddened) for hot stars, so O, B and Wolf-Rayet stars use the
  spectral-type temperature (Pecaut & Mamajek 2013 scale) when that is hotter. Stars without B-V use
  the spectral type.
* Radius: Stefan-Boltzmann from L_bol = 10^(-0.4 (M_V + BC_V - 4.74)) and Teff, with BC_V(Teff) from
  Flower (1996) as corrected by Torres (2010, AJ 140, 1158); capped at 1800 R_sun (estimates from
  reddened colours and spectroscopic distances can exceed the largest measured stars). The formula
  runs hot for M dwarfs, whose radii come out about half the true value (Proxima 0.07 instead of
  0.15 R_sun).
* Distances: HYG marks 10,218 stars without a usable Hipparcos parallax with 100,000 pc. Their
  distance is estimated from the spectral type and luminosity class (Schmidt-Kaler 1982 absolute
  magnitudes) with a cosecant extinction law (0.7 mag/kpc, dust scale height 110 pc). Without a
  luminosity class, the least luminous class consistent with an insignificant parallax (> 400 pc) is
  used. Results are limited to 400-6000 pc (5-25 pc for Gliese stars) with soft limits: each star's
  limits are moved inwards by a factor 10^(0.25 u), with u in [0, 1) from a hash of its HYG id, so the
  1,285 limited stars spread over 400-711 pc and 3374-6000 pc instead of forming shells (hard limits
  had put 1,189 stars at exactly 400 pc and 100 at exactly 6000 pc).
* Literature corrections (`STAR_OVERRIDES`, 8 stars): Eta Carinae (2.35 kpc, Smith 2006; 15,000 K)
  and VY Canis Majoris (1.17 kpc, Zhang et al. 2012); the Orion Nebula Cluster stars Theta1 Orionis A,
  C, D, Theta2 Orionis and NU Orionis at the cluster distance, 388 pc (Kounkel et al. 2017; HYG had
  spectroscopic distances of 0.98-1.18 kpc for the Trapezium and poor Hipparcos parallaxes for the
  other two), with Theta1 Ori A's V (6.73) and type (B0V) from SIMBAD instead of HYG's values for the
  blend; Mira at 3000 K and 350 R_sun (interferometry; its HYG colour gives 4800 K and 7 R_sun).
* Names (UTF-8): IAU proper names from HYG; otherwise Bayer or Flamsteed designations in full form
  ("Tau Ceti", "61 Cygni", "Pi5 Orionis"); otherwise Gliese numbers for stars within 10 pc.
  Components sharing a designation get " A", " B", ... (the Trapezium keeps its literature letters).
* Completeness (for suppressing duplicate procedural stars, `UniverseContent::catalogLimitAppMag` /
  `catalogRadiusPc`, both in terms of the observed V): the Hipparcos Survey is complete to
  V = 7.3 + 1.1 |sin b| (early types) and 7.9 + 1.1 |sin b| (late types), and HYG adds the bright-star
  and nearby-star catalogues, so **V = 7.5** is used. The radius is the 99th percentile of the
  distances of catalogue stars brighter than that, rounded up to 100 pc: **1500 pc** (249 of 25,687
  such stars lie farther out).

### Galaxies

* Precedence: McConnachie (2012) for the Local Group (distance moduli, position angles,
  ellipticities, M_V, half-light radii, stellar masses); UNGC for the Local Volume (distance moduli
  from its table 6, Holmberg diameters, axis ratios, inclinations, absolute B magnitudes, K-band
  luminosities); 2MRS for everything else (2MASS total Ks magnitudes, axis ratios, morphological
  types, velocities) with position angles from the 2MASS XSC; RC3 supplies optical D25 diameters,
  axis ratios, position angles, types and NGC/IC/UGC/PGC identifiers.
* Deduplication: UNGC entries merge with McConnachie ones by position (2 arcmin or 8% of the
  diameter) or name; 2MRS entries merge with local ones by position (1.5 arcmin or 10% of the size,
  consistent velocity, and K magnitude for loose matches) or catalogue name, including Messier/NGC
  aliases (2MRS lists M51 as "MESSIER_051a"). The Milky Way and the disputed Canis Major overdensity
  are excluded. 99 UNGC and 161 2MRS entries were merged.
* Positions come from the catalogue that created the entry, unless 2MASS and RC3 agree (within 30")
  on a centre more than 60" from it. That applies to one galaxy: UNGC puts NGC 5194 (M51) 2.3' north
  of its nucleus, half way to NGC 5195.
* Distances: redshift-independent where known (866 galaxies). Literature overrides: M31 761 kpc
  (Li et al. 2021, ApJ 920, 84), LMC 49.59 kpc (Pietrzynski et al. 2019), SMC 62.44 kpc (Graczyk et
  al. 2020). The 32 other members of McConnachie's M31 sub-group (M32, NGC 205, M33, IC 10, the
  Andromeda dwarfs, ...) are moved with M31 (x 761 / 783.4, McConnachie's M31 distance), so M32 stays
  22 kpc behind M31 as in the source instead of 44. Interacting pairs: when two galaxies with their own
  redshift-independent distances lie within 10 arcmin and 150 km/s of each other (and within 0.75 mag
  in distance modulus), the fainter takes the brighter's distance; this puts NGC 5195 at M51's distance
  (it was 0.74 Mpc in front) and aligns 21 other pairs, most of them already within 0.2 Mpc
  (`manifest.json` lists them). Otherwise the comoving distance of the redshift for a flat Lambda-CDM
  cosmology with **H0 = 70 km/s/Mpc**, Omega_m = 0.3, using the Local Group frame velocity
  (Karachentsev & Makarov 1996) below 2500 km/s, the CMB frame (Planck 2018 dipole) above 4500 km/s,
  and a linear blend in between (minimum 300 km/s). Members of nine clusters (selected by angle and
  velocity) are placed at the cluster distance, with a deterministic line-of-sight spread, to remove
  the "fingers of god" of redshift distances: Virgo 16.5 Mpc (Mei et al. 2007), Fornax 20.0 Mpc
  (Blakeslee et al. 2009), and the Hubble distances of Coma, Perseus, Centaurus, Hydra, Norma, Leo
  (A1367) and Antlia (`manifest.json` lists member counts and distances). The 1,066 galaxies without
  a redshift (mostly near the Galactic plane) get a photometric distance assuming M_K = -24.5 (the
  survey median).
* Sizes are expressed as optical D25-equivalent diameters. UNGC Holmberg diameters come first,
  **corrected for Galactic extinction**: table 2's linear A26 (corrected for Galactic extinction and
  inclination after Fouque & Paturel 1985; in the catalogue log A26/a26 is close to 0.094 A_B, the
  medians per A_B bin following it to 0.03 dex, minus up to 0.04 dex for edge-on disks) converted
  back to an angle with table 1's distance; table 1's angular a26 is as observed. Where A26
  is below 0.5 kpc (two decimals) the same law is applied to a26. Beyond A_B = 5 mag, where the law is
  extrapolated (HIZSS012 at A_B = 7.9 would grow 5.4x to 36 kpc), the correction is limited to its
  value at 5 mag unless the 2MASS size (K band, found by position in the XSC) is larger, and never
  exceeds the published value (7 galaxies). 54 galaxies grew by more than 1.3x, for example Maffei 1
  2.2 -> 9.6 kpc, Maffei 2 2.9 -> 12.4 kpc, IC 342 19.0 -> 31.5 kpc, Circinus 7.9 -> 18.6 kpc. The
  Holmberg-to-D25 ratio, 10^0.037, is the median a26/D25 over galaxies with A_B < 0.3. Otherwise RC3
  D25, else 2 x the 2MASS total radius times 10^-0.059 (median D25/(2 r_ext)). RC3 D25 and 2MASS sizes
  are not corrected for extinction: 2MRS avoids the Galactic plane (E(B-V) < 1, median 0.06), and the
  D25/(2 r_ext) ratio falls by ~0.03-0.05 dex per magnitude of A_B, so the ~340 galaxies with RC3 sizes
  and E(B-V) > 0.25 are roughly 10-30% too small.
* Inclination from the axis ratio with an intrinsic thickness of 0.20 (spirals), 0.25 (S0) or 0.35
  (irregulars), or UNGC's value. Overrides: the Sombrero (M104) 84 deg; the Whirlpool (M51) 22 deg,
  its kinematic inclination (Colombo et al. 2014, ApJ 784, 3; the tidal arm makes its isophotes look
  53 deg inclined). Ellipticals are modelled as oblate spheroids seen edge-on, so the projected shape
  matches the catalogue.
* Morphology: RC3, 2MRS, UNGC, McConnachie in that order; 18,987 faint 2MRS galaxies have no type and
  get one drawn deterministically from the field (cluster) mix: 15% (35%) E, 20% (35%) S0, 60% (27%)
  spirals, 5% (3%) irregulars. The SMC is typed irregular.
* Luminosity and mass: M_V from McConnachie, else UNGC B with a typical (B-V) for the type, else
  2MASS Ks with a typical V-K (Jarrett et al. 2003 B-K minus B-V), with the K correction
  -6 log10(1+z). Stellar masses from K-band luminosities with M/L_K = 0.8 (E/S0), 0.6 (spirals),
  0.5 (irregulars) (McGaugh & Schombert 2014), or McConnachie's masses; M31 uses 1.0e11 M_sun (Tamm
  et al. 2012; Sick et al. 2015) instead of the 3.1e10 from its 2MASS photometry.
* Names: common names with an identifier ("Andromeda Galaxy (M31)", "Whirlpool Galaxy (M51)",
  "Centaurus A (NGC 5128)", "Large Magellanic Cloud"), else "M49 (NGC 4472)", NGC/IC numbers, Local
  Group names ("Fornax Dwarf", "Andromeda XIX"), UGC/ESO/Arp/Mrk numbers. Distinct galaxies that
  share an identifier through ambiguous cross-identifications get an identifier of their own (or
  "#2"); 14 were renamed.

### Choices made in code (`RealUniverse.cpp`)

* Frames: ICRS -> galactocentric like astropy's Galactocentric frame: x towards Sgr A* (RA 266.41683708,
  Dec -29.00781056; Reid & Brunthaler 2004), the IAU north galactic pole orthogonalised against it,
  then a tilt so that the Sun is 20.8 pc above the plane at 8178 pc from Sgr A*; axes as in
  `Universe.h` (+X Sun -> centre, +Y north galactic pole).
* **De-reddening (convention shared with the renderer).** The renderer dims every star by the Milky
  Way model's dust between the camera and the star, so catalogue stars, whose V already contains the
  real dust towards the Sun, would be dimmed twice. The loader therefore sets
  `StarRecord::absMag = file absMag - A_V(Sun -> star)`, where A_V is the column of
  `host.dustExtinction()` along the straight segment (`real::hostDustColumnMag`: midpoint rule with
  20 pc steps, clipped to the host's bounding sphere and to 10 dust scale heights around its plane;
  against a 5 pc reference over 400 sight lines: rms 0.002 mag, worst 0.03 mag; 30-40 pc steps would
  miss or overweight the cores of the model's dust clouds by up to several magnitudes). With the
  renderer applying the same column from the camera, the sky seen from the Sun reproduces every
  catalogue V, and stars brighten or dim consistently elsewhere. Median A_V is 0.028 mag (90% below 0.22); where the model's dust is far thicker than the
  real dust in that direction (sight lines through dense model clouds towards the inner Galaxy), the
  intrinsic magnitude is capped at M_V = -10, the brightest real stars (56 stars, 3 of them
  naked-eye). This costs about 1.9 million dust evaluations, spread over the hardware threads: about
  250 ms of the ~300 ms load on the 16-thread test machine.
* Galaxy shape fields: besides ellipticals, disks also get `ellipticalRadiusPc` (measured half-light
  radius, else 1.678 h, an exponential disk's half-light radius) and `ellipticalAxisRatio` (irregulars:
  the intrinsic flattening min(b/a, 0.35) that matches the observed b/a at the catalogue inclination;
  lenticulars and spirals: the observed b/a, which the renderer uses for S0 sprites).
* Galaxy orientation: the major axis lies at the catalogue position angle and the disk normal is
  inclined by the catalogue inclination. Two further choices are not catalogued and come from the
  galaxy's seed: which side of the minor axis is nearer, and which face of the disk we see. The face
  sets the sense in which the model's arms wind on our sky (and the sense of rotation), so by default
  a face-on spiral is a mirror image of its photographs half of the time. Fixed instead: the near sides
  of M31 (north-west, its dust lanes cross the bulge there) and the LMC (north-east, van der Marel &
  Cioni 2001), and the arm winding of six famous spirals (`armWindingOverride`): clockwise outward on a
  north-up, east-left image for M51, M81, M101 and M31, counter-clockwise for M83 and M74. The
  windings were measured on DSS2 blue and red and GALEX NUV cutouts from the CDS hips2fits service:
  after deprojection with the catalogue PA and inclination, the phase of the m = 2, 3 and 4 azimuthal
  harmonics (minus their radial mean, which removes bars and ovals) rotates monotonically with log
  radius, and the sign agreed across surveys and harmonics (for example M101: +11.8, +11.5 and +6.0 rad
  for m = 2 in the three surveys). Log-polar Fourier spectra (Puerari & Dottori 1992) agree, and
  deprojected renderings were checked by eye for M51, M81 and M83. M51 only gave a clear answer once
  its position was corrected (see Positions above). M31 is
  too inclined for images: its south-west half approaches (Chemin et al. 2009, ApJ 705, 1395), its
  north-west side is near and its arms trail, so it rotates counter-clockwise on the sky and its arms
  wind clockwise outward. M33 gave inconsistent answers and keeps the seeded orientation.
* Gargantua (placement "near the Sun") lies 30 light years from the Sun towards RA 158.682,
  Dec -26.137 (Antlia/Hydra, l = 268.3, b = +27.4). The direction was found by scanning 40,000
  directions with 10 deg < |b| < 35 deg for the largest angular distance from all 176 stars brighter
  than V = 3 (23.4 deg) such that no catalogue star is within 2 pc of the hole (nearest: 2.08 pc).
